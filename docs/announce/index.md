# 隱私權政策

> *最後更新日期：2026 年 9 月 23 日*

為保障您的權益，請詳細閱讀本隱私權政策。當您於 Discord 伺服器中使用「星野咲子」（以下稱「本機器人」）時，即表示您同意本政策所述之資料蒐集、處理及利用方式。

## 一、適用範圍

本政策適用於本機器人及本網站所提供之服務，不適用於經由本機器人或本網站連結之第三方網站與服務（包含但不限於 Discord、Twitch）。第三方服務之資料處理，請參閱其各自的隱私權政策。

## 二、資料之蒐集

本機器人僅蒐集提供服務所必要之資料：

### 由 Discord 提供之公開資訊

- 使用者 ID、顯示名稱
- 伺服器 ID、伺服器名稱、成員數
- 頻道 ID、訊息 ID、身分組 ID

### 使用者主動設定之內容

- 關鍵字回覆規則（關鍵字、回覆內容、比對類型及設定者）
- 反應身分組面板之設定（頻道、標題、說明、表情符號與身分組對應）
- 成員進出通知之設定（通知頻道、啟用狀態、訊息模板）
- 直播通知之設定（通知頻道、訊息模板、監控中之實況主名單）

### 訊息內容之處理

本機器人僅於訊息傳送當下在記憶體中進行關鍵字比對，**不會儲存、記錄或上傳您的訊息內容**。

## 三、資料之處理及利用

蒐集之資料僅用於下列用途：

- 提供本機器人之各項功能（關鍵字回覆、身分組發派、成員通知、直播通知、狀態查詢）
- 維持服務正常運作與問題排查

本機器人**不會**將您的資料用於廣告投放、使用者行為分析，亦不會出售、出租或以任何形式提供予無關之第三方。

## 四、資料之儲存與保護

- 本機器人架設於 Oracle Cloud Infrastructure（OCI）之 Compute 執行個體上，相關設定資料儲存於該主機之資料庫中
- 僅開發人員本人可接觸主機與資料庫，並採取合理之技術性防護措施
- 惟網路傳輸與儲存無法保證百分之百安全，若發生影響您權益之資料事件，將於合理範圍內通知

## 五、資料之保留與刪除

- 各項設定資料於對應功能停用前持續保留；當本機器人被移出伺服器時，該伺服器之所有設定資料將自動刪除
- 伺服器管理員可隨時透過指令刪除相關設定（如 `/keyword delete`、`/reaction-role panel delete`、`/notify member disable`、`/notify stream disable`）
- 如需刪除伺服器之全部資料或有其他資料權利相關請求，請透過下方聯絡方式與開發者聯繫

## 六、政策之變更

本政策可能因功能調整或法令要求而修訂。修訂後之內容將公布於本頁，並更新最後更新日期，恕不另行個別通知。建議您定期查閱本頁以取得最新資訊。
