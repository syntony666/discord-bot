# 指令說明

#### 所有指令都是斜線指令(/)，在訊息框打 `/` 就會跳出來，而且只能在伺服器內使用

`<必填>` `[選填]`

## 指令總覽

| 指令 | 用途 | 需要的權限 |
|---|---|---|
| `/keyword` | 設定關鍵字，有人命中就自動回覆 | 無，人人都能用 |
| `/reaction-role` | 對訊息按表情符號領取身分組 | 管理身分組 |
| `/notify` | 成員進出、實況開台通知 | 管理伺服器 |
| `/status` | 查看機器人與伺服器狀態 | 無 |

## 關鍵字自動回覆 `/keyword`

> 設定好關鍵字之後，只要有人說出對應的話，工具人就會自動幫你回

舉例來說，設定關鍵字「早安」、回覆「早！」，之後只要有成員打「早安」，工具人就會回「早！」

### 新增回覆 `/keyword add`

- 指令: `/keyword add <關鍵字> <回覆內容> [比對類型]`

| 參數 | 說明 |
|---|---|
| `關鍵字` | 用來觸發回覆的文字 |
| `回覆內容` | 命中時工具人要回的話。想讓它隨機回答，就用 `;;` 分隔多個選項，例如 `早安;;早;;哈囉` |
| `比對類型` | 不填預設 `EXACT`：整句話要跟關鍵字**完全一樣**才會回；`CONTAINS`：句子裡**有包含**關鍵字就會回 |

::: tip

同一個關鍵字不能重複設定，重複會被拒絕並顯示原本的規則，想改內容請用 `/keyword edit`

`CONTAINS` 比較敏感，例如關鍵字設「早安」，有人打「大家早安啊」也會命中

:::

### 修改回覆 `/keyword edit`

- 指令: `/keyword edit <關鍵字> <新回覆內容> [比對類型]`

關鍵字必須已經存在，用這個指令改掉它的回覆內容或比對方式

### 刪除回覆 `/keyword delete`

- 指令: `/keyword delete <關鍵字>`

### 查看所有回覆 `/keyword list`

> 列出伺服器所有回覆規則（關鍵字、回覆內容、比對類型、設定者），可以翻頁

- 指令: `/keyword list`

### 查看單一規則 `/keyword view`

> 列表裡只顯示摘要，想看某條規則的完整回覆內容用這個

- 指令: `/keyword view <關鍵字>`

### 搜尋規則 `/keyword search`

- 指令: `/keyword search <關鍵字>`

::: tip

比對時訊息前後的空白會先去掉，但**有分大小寫**

一句話如果同時命中好幾條規則，只會回第一條

如果工具人在那個頻道沒有發言權限，就只會默默記著，不會洗版

:::

## 自動發派身分組 `/reaction-role`

_**僅限擁有「管理身分組」權限者執行**_

> 發一個領取身分組的面板（Panel），成員對面板按表情符號就能拿到對應身分組，不用再麻煩管理員

### 使用流程

1. `panel create` 在頻道發一個 Panel
2. `add` 幫 Panel 加上「表情符號 → 身分組」的對應，工具人會自動幫 Panel 補上那個表情符號讓大家按
3. 成員對 Panel 按表情符號 → 拿到身分組；取消反應 → 收回身分組

### 建立 Panel `/reaction-role panel create`

- 指令: `/reaction-role panel create <頻道> [標題] [說明] [模式]`

| 參數 | 說明 |
|---|---|
| `頻道` | Panel 要發到哪個文字頻道 |
| `標題` | Panel 的大標題（上限 256 字），不填用預設 |
| `說明` | 標題下面的說明文字（上限 2048 字） |
| `模式` | 不填預設 `NORMAL`，三種模式的差別見下方 |

### Panel 模式

| 模式 | 按反應時 | 取消反應時 | 適合情境 |
|---|---|---|---|
| `NORMAL`（預設） | 拿到對應身分組，可以同時領多個 | 收回該身分組 | 想自選多個身分組（如興趣、通知群） |
| `UNIQUE` | 先收回其他身分組、清掉其他反應，再給新的，**保證單選** | 收回該身分組 | 只能選一個（如地區、陣營） |
| `VERIFY` | 給身分組後**馬上收掉你的反應** | **不收回**身分組 | 一次性驗證（如同意規則後放行） |

### 管理 Panel

- 指令: `/reaction-role panel list` — 列出所有 Panel（含 panel_id、模式、所在頻道）
- 指令: `/reaction-role panel edit <panel_id> [標題] [說明] [模式]` — 只更新有填的欄位，Panel 會即時更新
- 指令: `/reaction-role panel delete <panel_id>` — 刪除整個 Panel

### 新增身分組對應 `/reaction-role add`

> 在既有的 Panel 上新增「表情符號 → 身分組」的對應

- 指令: `/reaction-role add <panel_id> <表情符號> <身分組> [說明]`

| 參數 | 說明 |
|---|---|
| `panel_id` | Panel 訊息的 ID，就顯示在 Panel 底部，可以直接複製 |
| `表情符號` | 直接貼表情符號或伺服器的自訂表情符號 |
| `身分組` | 按下表情符號後要給的身分組 |
| `說明` | 這個身分組的說明，會顯示在 Panel 上（上限 100 字） |

### 移除 / 查看對應

- 指令: `/reaction-role remove <panel_id> <表情符號>` — 移除某個表情符號的對應
- 指令: `/reaction-role role-list <panel_id>` — 列出 Panel 上所有的對應

::: tip

工具人的身分組必須排在欲發派的身分組**上面**，才發得出去

只有 Panel 訊息上的反應有效，對其他訊息按表情不會有作用

:::

## 直播通知 `/notify stream`

_**僅限擁有「管理伺服器」權限者執行**_

> 監控實況主，開台的時候在指定頻道發通知（目前支援 Twitch）

### 使用流程

1. `enable` 設定通知要發到哪個頻道
2. `watch` 加入想監控的實況主，可以加好幾個
3. 之後實況主一開台就會自動發通知

### 啟用通知 `/notify stream enable`

- 指令: `/notify stream enable <頻道> [訊息內容]`

| 參數 | 說明 |
|---|---|
| `頻道` | 通知要發到哪個文字頻道 |
| `訊息內容` | 通知卡片上方的自訂文字（上限 1000 字），`{user}` 會換成實況主名稱；不填就只發通知卡片 |

已經設定過再下 `enable` 的話，會更新頻道並重新啟用；沒填 `訊息內容` 就會保留原本的訊息

### 停用通知 `/notify stream disable`

> 只關掉通知，設定和監控名單都會保留，重新 `enable` 就能恢復

- 指令: `/notify stream disable`

### 加入監控 `/notify stream watch`

- 指令: `/notify stream watch <platform> <實況主ID或用戶名> [顯示名稱]`

| 參數 | 說明 |
|---|---|
| `platform` | 目前只有 `twitch` |
| `實況主ID或用戶名` | 貼實況主的帳號名稱就可以了，會自動轉換 |
| `顯示名稱` | 通知裡顯示的名字（上限 100 字），不填就用帳號名 |

::: tip

同一個頻道重複加入會被拒絕

:::

### 移除監控 / 查看設定

- 指令: `/notify stream unwatch <platform> <實況主ID或用戶名>` — 停止監控某個實況主
- 指令: `/notify stream list` — 查看啟用狀態、通知頻道、訊息模板和所有監控中的實況主

::: tip

每 60 秒檢查一次開台狀態，只在**離線轉開台**的瞬間通知一次，不會連發洗版；關台不會通知

通知會是一張「🔴 正在直播！」的卡片，附實況標題、連結、遊戲分類和縮圖

:::

## 成員進出通知 `/notify member`

_**僅限擁有「管理伺服器」權限者執行**_

> 有新成員加入、或有人離開伺服器時，在指定頻道發送通知訊息

### 啟用通知 `/notify member enable`

> 一個指令就會把「加入 + 離開」兩種通知開到同一個頻道

- 指令: `/notify member enable <頻道>`

### 關閉通知 `/notify member disable`

> 關閉所有成員通知，執行前會跳出確認對話框，列出目前啟用中的通知

- 指令: `/notify member disable`

### 查看 / 設定個別通知 `/notify member join`、`/notify member leave`

> 不帶參數是查看目前的設定；帶參數就會更新（更新前會跳確認對話框）

- 指令: `/notify member join` — 查看加入通知的狀態、頻道、訊息模板
- 指令: `/notify member join [訊息模板] [true|false]` — 更新加入通知的模板或開關
- 指令: `/notify member leave` — 查看離開通知的設定
- 指令: `/notify member leave [訊息模板] [true|false]` — 更新離開通知的模板或開關

訊息模板可以用的變數：

| 變數 | 會變成 |
|---|---|
| `{user}` | 標記該成員（@成員） |
| `{username}` | 成員的顯示名稱 |
| `{server}` | 伺服器名稱 |
| `{memberCount}` | 目前的成員數 |

沒有自訂時的預設訊息：

- 加入：`📥 {user} 加入了 {server}！目前共 {memberCount} 位成員`
- 離開：`📤 {username} 離開了 {server}。目前剩餘 {memberCount} 位成員`

### 查看狀態 / 測試預覽

- 指令: `/notify member status` — 查看加入 / 離開通知各自的開關狀態、頻道、目前訊息模板
- 指令: `/notify member test <join|leave>` — 在**目前頻道**預覽通知長什麼樣子，會用你自己的資訊帶入變數，不會真的發到通知頻道

::: tip

通知是用訊息卡片發送，加入和離開各有不同的顏色

:::

## 取得相關資訊 `/status`

> 純查詢用，不會動到任何設定

- 指令: `/status bot` — 機器人版本、上線時間、API 與 Discord 連線狀態
- 指令: `/status guild` — 伺服器名稱、成員數、建立時間等
- 指令: `/status features` — 各功能的啟用狀態總覽
