# 指令說明

#### 所有指令都是斜線指令（/），在訊息框打 `/` 就會跳出來，而且只能在伺服器內使用

`<必填>` `[選填]`

## 指令總覽

| 指令             | 用途                           | 需要的權限     |
| ---------------- | ------------------------------ | -------------- |
| `/keyword`       | 設定關鍵字，有人命中就自動回覆 | 無，人人都能用 |
| `/random`        | 抽籤、骰子、亂數               | 無             |
| `/linkfix`       | 手動清理一條連結               | 無             |
| `/auto linkfix`  | 訊息裡的連結自動修復預覽       | 管理伺服器     |
| `/reaction-role` | 對訊息按表情符號領取身分組     | 管理身分組     |
| `/say`           | 讓工具人代發訊息卡片           | 管理伺服器     |
| `/clear`         | 批次刪除頻道訊息               | 管理訊息       |
| `/notify`        | 成員進出、實況開台、刪訊記錄   | 管理伺服器     |
| `/status`        | 查看機器人與伺服器狀態         | 無             |

## 伺服器級別

> 每個伺服器都有一個級別，決定各功能可以設定的數量上限

| 級別                | 關鍵字規則 | 實況監控 | 身分組選單 |
| ------------------- | ---------- | -------- | ---------- |
| ⚪ `NORMAL`（預設） | 20         | 3        | 3          |
| 🟣 `PREMIUM`        | 100        | 10       | 10         |
| 🟡 `HOME`           | 無限       | 無限     | 無限       |

- 指令: `/status guild` — 查看自己伺服器的級別和各功能的目前用量

::: tip

新增時超過上限會被擋下來，並提示「已達上限」

級別是以伺服器計算的，同一個人在不同伺服器可能看到不同上限

:::

## 關鍵字自動回覆 `/keyword`

> 設定好關鍵字之後，只要有人說出對應的話，工具人就會自動幫你回

舉例來說，設定關鍵字「早安」、回覆「早！」，之後只要有成員打「早安」，工具人就會回「早！」

### 新增回覆 `/keyword add`

- 指令: `/keyword add <關鍵字> <回覆內容> [比對類型]`

| 參數       | 說明                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| `關鍵字`   | 用來觸發回覆的文字                                                                             |
| `回覆內容` | 命中時工具人要回的話。想讓它隨機回答，就用 `;;` 分隔多個選項，例如 `早安;;早;;哈囉`            |
| `比對類型` | 不填預設 `EXACT`：整句話要跟關鍵字**完全一樣**才會回；`CONTAINS`：句子裡**有包含**關鍵字就會回 |

::: tip

同一個關鍵字重複設定時，會跳出「確認覆寫」讓你比對新舊內容後直接覆蓋

`CONTAINS` 比較敏感，例如關鍵字設「早安」，有人打「大家早安啊」也會命中

:::

### 修改回覆 `/keyword edit`

- 指令: `/keyword edit <關鍵字> <新回覆內容> [比對類型]`

關鍵字必須已經存在，用這個指令改掉它的回覆內容或比對方式

### 刪除回覆 `/keyword delete`

> 刪除前會跳出「確認刪除」並顯示該規則的內容，確認後才刪

- 指令: `/keyword delete <關鍵字>`

### 查看所有回覆 `/keyword list`

> 列出伺服器所有回覆規則（關鍵字、回覆內容、比對類型、設定者），可以翻頁

- 指令: `/keyword list`

### 查看單一規則 `/keyword view`

> 列表裡只顯示摘要，想看某條規則的完整回覆內容用這個

- 指令: `/keyword view <關鍵字>`

結果下方有「複製 / 修改回覆」按鈕，按下去會開啟已預填目前內容的表單，改完送出就直接更新規則

### 搜尋規則 `/keyword search`

- 指令: `/keyword search <關鍵字>`

::: tip

比對時訊息前後的空白會先去掉，但**有分大小寫**

一句話如果同時命中好幾條規則，只會回第一條

如果工具人在那個頻道沒有發言權限，就只會默默記著，不會洗版

關鍵字規則的數量受伺服器級別限制，見上方「伺服器級別」

確認訊息只有你看得到；「複製 / 修改回覆」這類互動按鈕僅限原使用者按，5 分鐘後會自動失效，過期再按會顯示「操作已過期」

:::

## 隨機功能 `/random`

> 想在群裡抽一個、擲骰子或產生亂數，馬上用就有

### 抽籤 `/random pick`

- 指令: `/random pick <選項>`

選項用 `,`、`，`、`;`、`；`、`、` 分隔，例如 `/random pick 便當,麵,飯糰` 就會從三個裡抽一個

### 擲骰子 `/random roll`

- 指令: `/random roll [骰子]`

不填預設 `1d6`；格式是 `NdM`（N 顆 M 面），後面可以加 `kh`（留最高）、`kl`（留最低）、`dh`（丟最高）、`dl`（丟最低），例如 `4d6kh3` 是「擲 4 顆 6 面骰，留最高的 3 顆」

### 隨機整數 `/random number`

- 指令: `/random number [最小值] [最大值]`

不填預設 1～100

## 連結修復 `/linkfix`、`/auto linkfix`

> X、Instagram、TikTok、Pixiv、Threads、Facebook 貼到 Discord 常常預覽不出來，工具人幫你換成能預覽的連結

### 手動清理 `/linkfix`

- 指令: `/linkfix <連結>`

回傳清理完的連結：支援的站點會換成可預覽的網址、短網址（bit.ly、reurl.cc 這類）會展開、`utm`、`fbclid` 這種追蹤參數會清掉

### 自動修復 `/auto linkfix`

_**僅限擁有「管理伺服器」權限者執行**_

啟用後，訊息裡出現上述站點的連結時，工具人會把壞掉的預覽壓掉、改貼修好的連結

- 指令: `/auto linkfix enable` — 啟用
- 指令: `/auto linkfix disable` — 停用
- 指令: `/auto linkfix status` — 查看啟用狀態

::: tip

不想被修的連結用 `<>` 包起來就會跳過；隱藏文字（spoiler）裡的連結也不會動

手動 `/linkfix` 不用先啟用，隨時都能用

:::

## 自動發派身分組 `/reaction-role`

_**僅限擁有「管理身分組」權限者執行**_

> 發一個領取身分組的選單，成員對選單訊息按表情符號就能拿到對應身分組，不用再麻煩管理員

### 使用流程

1. `panel create` 在頻道發一個選單
2. `add` 幫選單加上「表情符號 → 身分組」的反應身分組，工具人會自動幫選單補上那個表情符號讓大家按
3. 成員對選單按表情符號 → 拿到身分組；取消反應 → 收回身分組

### 建立選單 `/reaction-role panel create`

- 指令: `/reaction-role panel create <頻道> [標題] [說明] [模式]`

| 參數   | 說明                                    |
| ------ | --------------------------------------- |
| `頻道` | 選單要發到哪個文字頻道                  |
| `標題` | 選單的大標題（上限 256 字），不填用預設 |
| `說明` | 標題下面的說明文字（上限 2048 字）      |
| `模式` | 不填預設 `NORMAL`，三種模式的差別見下方 |

### 選單模式

| 模式             | 按反應時                                               | 取消反應時       | 適合情境                           |
| ---------------- | ------------------------------------------------------ | ---------------- | ---------------------------------- |
| `NORMAL`（預設） | 拿到對應身分組，可以同時領多個                         | 收回該身分組     | 想自選多個身分組（如興趣、通知群） |
| `UNIQUE`         | 先收回其他身分組、清掉其他反應，再給新的，**保證單選** | 收回該身分組     | 只能選一個（如地區、陣營）         |
| `VERIFY`         | 給身分組後**馬上收掉你的反應**                         | **不收回**身分組 | 一次性驗證（如同意規則後放行）     |

### 管理選單

- 指令: `/reaction-role panel list` — 列出所有身分組選單（含選單 ID、模式、所在頻道）
- 指令: `/reaction-role panel edit <panel_id> [標題] [說明] [模式]` — 只更新有填的欄位，選單訊息會即時更新
- 指令: `/reaction-role panel delete <panel_id>` — 刪除整個選單

### 新增反應身分組 `/reaction-role add`

> 在既有的選單上新增「表情符號 → 身分組」的對應

- 指令: `/reaction-role add <panel_id> <表情符號> <身分組> [說明]`

| 參數       | 說明                                            |
| ---------- | ----------------------------------------------- |
| `panel_id` | 選單訊息的 ID，顯示在選單頁尾，可以直接複製     |
| `表情符號` | 直接貼表情符號或伺服器的自訂表情符號            |
| `身分組`   | 按下表情符號後要給的身分組                      |
| `說明`     | 這個身分組的說明，會顯示在選單上（上限 100 字） |

### 移除 / 查看反應身分組

- 指令: `/reaction-role remove <panel_id> <表情符號>` — 移除選單上某個表情符號的身分組
- 指令: `/reaction-role role-list <panel_id>` — 列出選單上所有反應身分組

::: tip

工具人的身分組必須排在要給予的身分組**上面**，才給得出去

只有選單訊息上的反應有效，對其他訊息按表情不會有作用

選單的數量受伺服器級別限制，見上方「伺服器級別」

:::

## 代發訊息 `/say`

_**僅限擁有「管理伺服器」權限者執行**_

> 讓工具人以訊息卡片的形式，在目前頻道代你發公告

- 指令: `/say <訊息內容> [標題]`

| 參數       | 說明                                  |
| ---------- | ------------------------------------- |
| `訊息內容` | 卡片內文（上限 4000 字），`\n` 會換行 |
| `標題`     | 卡片大標題（上限 256 字），不填就沒有 |

::: tip

送出前會先跳出**預覽**（只有你看得到），確認後才真正發出；預覽 2 分鐘後自動失效

發出的卡片頁尾會署名發送者，誰發的一目了然

:::

## 批次刪除訊息 `/clear`

_**僅限擁有「管理訊息」權限者執行**_

> 一次清掉頻道裡最近的訊息，洗版或吵架現場善後用

### 依數量 `/clear count`

- 指令: `/clear count <數量>` — 刪除最近 1～100 則

### 依時間 `/clear time`

- 指令: `/clear time <分鐘>` — 刪除最近 1～1440 分鐘內的訊息

::: tip

執行前會顯示確認（包含實際可刪的數量），確認後才刪

**釘選的訊息會被跳過**；超過 14 天的訊息 Discord 不給批次刪，會在結果裡回報略過數

:::

## 直播通知 `/notify stream`

_**僅限擁有「管理伺服器」權限者執行**_

> 監控實況主，開台的時候在指定頻道發通知（目前支援 Twitch）

### 使用流程

1. `enable` 設定通知要發到哪個頻道
2. `watch` 加入想監控的實況主，可以加好幾個
3. 之後實況主一開台就會自動發通知

### 啟用通知 `/notify stream enable`

- 指令: `/notify stream enable <頻道> [訊息內容]`

| 參數       | 說明                                                                                  |
| ---------- | ------------------------------------------------------------------------------------- |
| `頻道`     | 通知要發到哪個文字頻道                                                                |
| `訊息內容` | 通知卡片上方的自訂文字（上限 1000 字），`{user}` 會換成實況主名稱；不填就只發通知卡片 |

已經設定過再下 `enable` 的話，會更新頻道並重新啟用；沒填 `訊息內容` 就會保留原本的訊息

### 停用通知 `/notify stream disable`

> 只關掉通知，設定和監控名單都會保留，重新 `enable` 就能恢復

- 指令: `/notify stream disable`

### 加入監控 `/notify stream watch`

- 指令: `/notify stream watch <platform> <實況主 ID 或使用者名稱> [顯示名稱]`

| 參數                     | 說明                                            |
| ------------------------ | ----------------------------------------------- |
| `platform`               | 目前只有 `twitch`                               |
| `實況主 ID 或使用者名稱` | 貼實況主的帳號名稱就可以了，會自動轉換          |
| `顯示名稱`               | 通知裡顯示的名字（上限 100 字），不填就用帳號名 |

::: tip

同一個頻道重複加入會被拒絕

監控數量受伺服器級別限制，見上方「伺服器級別」

:::

### 移除監控 / 查看設定

- 指令: `/notify stream unwatch <platform> <實況主 ID 或使用者名稱>` — 停止監控某個實況主
- 指令: `/notify stream list` — 查看啟用狀態、通知頻道、訊息範本和所有監控中的實況主

::: tip

每 60 秒檢查一次開台狀態，只在**離線轉開台**的瞬間通知一次，不會連發洗版；關台不會通知

通知會是一張「🔴 正在直播！」的卡片，附實況標題、連結、遊戲分類和縮圖

:::

## 成員進出通知 `/notify member`

_**僅限擁有「管理伺服器」權限者執行**_

> 有新成員加入、或有人離開伺服器時，在指定頻道發送通知訊息

### 啟用通知 `/notify member enable`

> 一個指令就會把「加入 + 離開」兩種通知開到同一個頻道

- 指令: `/notify member enable <頻道>`

### 關閉通知 `/notify member disable`

> 關閉所有成員通知，執行前會跳出只有你看得到的確認訊息，列出目前啟用中的通知

- 指令: `/notify member disable`

### 查看 / 設定個別通知 `/notify member join`、`/notify member leave`

> 不帶參數是查看目前的設定；帶參數就會更新（更新前會跳出只有你看得到的確認訊息）

- 指令: `/notify member join` — 查看加入通知的狀態、頻道、訊息範本
- 指令: `/notify member join [訊息範本] [true|false]` — 更新加入通知的範本或開關
- 指令: `/notify member leave` — 查看離開通知的設定
- 指令: `/notify member leave [訊息範本] [true|false]` — 更新離開通知的範本或開關

訊息範本可以用的變數：

| 變數            | 會變成              | 加入 | 離開 |
| --------------- | ------------------- | ---- | ---- |
| `{user}`        | 標記該成員（@成員） | ✅   | ❌   |
| `{username}`    | 成員的顯示名稱      | ✅   | ✅   |
| `{server}`      | 伺服器名稱          | ✅   | ✅   |
| `{memberCount}` | 目前的成員數        | ✅   | ✅   |

離開的成員已經不在伺服器，無法被標記；離開範本寫 `{user}` 的話只會顯示成員名稱。

沒有自訂時的預設訊息：

- 加入：`📥 {user} 加入了 {server}！目前共 {memberCount} 位成員`
- 離開：`📤 {username} 離開了 {server}。目前剩餘 {memberCount} 位成員`

### 查看狀態 / 測試預覽

- 指令: `/notify member status` — 查看加入 / 離開通知各自的開關狀態、頻道、目前訊息範本
- 指令: `/notify member test <join|leave>` — 在**目前頻道**預覽通知長什麼樣子，會用你自己的資訊帶入變數，不會真的發到通知頻道

::: tip

通知是用訊息卡片發送，加入和離開各有不同的顏色

:::

## 刪除訊息記錄 `/notify message-delete`

_**僅限擁有「管理伺服器」權限者執行**_

> 有人的訊息被刪掉時，把內容記錄到指定頻道，吵架刪訊滅證就抓得到

- 指令: `/notify message-delete enable <頻道>` — 啟用，監看全伺服器的頻道
- 指令: `/notify message-delete disable` — 關閉
- 指令: `/notify message-delete status` — 查看目前設定
- 指令: `/notify message-delete ignore <頻道>` — 排除某個頻道，該頻道的刪除不記錄
- 指令: `/notify message-delete unignore <頻道>` — 取消排除

::: tip

記錄卡片會顯示被刪的內容（太長會截斷）、所在頻道、附件數量、作者與原訊息的送出時間

要工具人看得到訊息才能記錄；如果訊息是在工具人上線前發的，內容來不及快取就記不到

:::

## 取得相關資訊 `/status`

> 純查詢用，不會動到任何設定

- 指令: `/status bot` — 機器人版本、上線時間、API 與 Discord 連線狀態
- 指令: `/status guild` — 伺服器名稱、級別、各功能用量、成員數、建立時間等
- 指令: `/status features` — 各功能的啟用狀態總覽
